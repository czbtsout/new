# ПОРОГ (The Threshold)

Высококачественный концепт однопользовательской игры нового поколения.

## О проекте
«ПОРОГ» — это атмосферное приключение, сочетающее в себе передовую графику, интуитивный UX и уникальную механику «Хроно-резонанса».

## Как запустить игру (Быстрый старт)

### 🚀 Windows (Рекомендуется):
Просто запустите файл **`start_windows.bat`** двойным щелчком мыши.
- **НОВОЕ:** Теперь игра запускается в графическом окне с **поддержкой мыши**.
- Вы можете нажимать кнопки интерфейса курсором для управления Резонатором.

### 💻 macOS / Linux / Консоль:
Запустите главный загрузчик:
```bash
python3 run_game.py
```
*Если графическая среда недоступна, игра автоматически переключится в текстовый режим.*

---

## Управление
- **Мышь:** Кликайте по кнопкам в окне игры для активации механик.
- **Клавиатура (в текстовом режиме):**
  - **R / К** — Активировать Резонатор.
  - **Q / Й** — Выйти.

## Структура проекта
- `run_game.py` — Главный загрузчик (пробует GUI, затем CLI).
- `proto/gui_prototype.py` — Исходный код графической версии (управление мышью).
- `proto/resonance_logic.py` — Исходный код текстовой версии.
- `CONCEPT.md` — Детальное описание геймплея.
- `UI_UX.md` — Дизайн-система.

## Ключевые особенности
- **Погружение:** Диегетический интерфейс и отсутствие традиционного обучения.
- **Инновации:** Механика взаимодействия с объектами из прошлого в реальном времени.
- **Эстетика:** Минималистичный премиум-дизайн с фокусом на кириллицу.
