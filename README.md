# ПОРОГ (The Threshold)

Высококачественный концепт однопользовательской игры нового поколения.

## О проекте
«ПОРОГ» — это атмосферное приключение, сочетающее в себе передовую графику, интуитивный UX и уникальную механику «Хроно-резонанса».

## Структура репозитория
- `CONCEPT.md` — Детальное описание геймплея, мира и механик.
- `UI_UX.md` — Дизайн-система и описание интерфейса на русском языке.
- `proto/` — Технический прототип механики резонанса (Python).
- `docs/` — Дополнительные материалы по визуальному и аудио стилям.

## Как запустить прототип
Для ознакомления с логикой механики «Хроно-резонанса», запустите:
```bash
python3 proto/resonance_logic.py
```

## Ключевые особенности
- **Погружение:** Диегетический интерфейс и отсутствие традиционного обучения.
- **Инновации:** Механика взаимодействия с объектами из прошлого в реальном времени.
- **Эстетика:** Минималистичный премиум-дизайн с фокусом на кириллицу.
