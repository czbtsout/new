# ПОРОГ (The Threshold)

Высококачественный концепт однопользовательской игры нового поколения.

## О проекте
«ПОРОГ» — это атмосферное приключение, сочетающее в себе передовую графику, интуитивный UX и уникальную механику «Хроно-резонанса».

## Как запустить игру (Быстрый старт)

### 🚀 Windows (Самый простой способ):
Просто запустите файл **`start_windows.bat`** двойным щелчком мыши. Он сам найдет Python и запустит игру.

### 💻 macOS / Linux / Вручную:
Запустите главный загрузчик из корневой папки:
```bash
python3 run_game.py
```

## Структура проекта
- `run_game.py` — Главный загрузчик игры (рекомендуется для запуска).
- `CONCEPT.md` — Детальное описание геймплея, мира и механик.
- `UI_UX.md` — Дизайн-система и описание интерфейса.
- `proto/` — Папка с исходным кодом логики.
- `docs/` — Дополнительные материалы.

## Ключевые особенности
- **Погружение:** Диегетический интерфейс и отсутствие традиционного обучения.
- **Инновации:** Механика взаимодействия с объектами из прошлого в реальном времени.
- **Эстетика:** Минималистичный премиум-дизайн с фокусом на кириллицу.
