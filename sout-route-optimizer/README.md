# 🚐 СОУТ - Сервис оптимизации маршрутов водителя

Сервис для построения и расчёта оптимального маршрута водителя, который обслуживает организации по Алтайскому краю в рамках специальной оценки условий труда (СОУТ).

## 📋 Описание

Организация находится в Барнауле. Выездной сотрудник-водитель объезжает организации по Алтайскому краю, проводит обслуживание рабочих мест и затем возвращается в Барнаул.

### Цель сервиса
Сформировать оптимальный маршрут на заданное количество дней так, чтобы:
- ✅ Был минимальный расход на поездку
- ✅ Было максимальное количество обслуженных рабочих мест
- ✅ Маршрут строился с учётом географии (по дорогам)
- ✅ Водитель не ездил туда-обратно по уже пройденному пути без необходимости
- ✅ Обязательно учитывался возврат в Барнаул

## 🚀 Быстрый старт

### Установка зависимостей
```bash
cd sout-route-optimizer
npm install
```

### Запуск сервера
```bash
npm start
```

Сервер запустится на порту 3000: http://localhost:3000

## 📊 Входные данные

Пользователь может указать:
- **Список организаций** с адресами/координатами (в формате JSON)
- **Загрузить Excel файл** (.xlsx, .xls) с данными организаций
- **Количество дней поездки** (1-10 дней)
- **Сумму командировочных** (рублей в день)

### Формат данных организации (JSON)
```json
[
  {
    "id": 1,
    "name": "ООО 'Пример'",
    "address": "Барнаул, улица Ленина, 10",
    "lat": 53.3606,
    "lng": 83.7617,
    "workplaces": 15
  }
]
```

### Формат Excel файла
Excel файл должен содержать следующие колонки (распознаются автоматически):
- **Организация** (или Название, Name, Org) — название организации
- **Адрес** (или Address, Location) — адрес организации
- **Рабочие места** (или Рабочих мест, Кол-во, Workplaces, Count) — количество рабочих мест
- **Широта** (или Lat, Latitude) — широта координат (опционально)
- **Долгота** (или Долгота, Lng, Lon, Longitude) — долгота координат (опционально)

Если координаты не указаны, сервис автоматически выполнит геокодирование адресов.

Если список организаций не указан, используются данные по умолчанию (10 организаций в различных городах Алтайского края).

## ⚙️ Логика расчёта

При построении маршрута учитываются:
- **Себестоимость поездки**: 14 рублей за 1 км
- **Время обслуживания**: 30 минут на организацию (независимо от количества рабочих мест)
- **Максимальное время работы в день**: 8 часов (480 минут)
- **Средняя скорость**: 60 км/ч

### Алгоритм оптимизации
Используется жадный алгоритм с возвратом в Барнаул:
1. Каждый день начинается и заканчивается в Барнауле
2. Выбирается ближайшая организация с учётом возможности вернуться в Барнаул до конца рабочего дня
3. Маршрут строится последовательно, минимизируя общий пробег

## 📈 Результаты расчёта

Сервис показывает:
- 🗺️ **Оптимальный маршрут по дням** с визуализацией на карте
- 📍 **Порядок посещения организаций** с адресами и расстояниями
- 📏 **Общее расстояние маршрута** (км)
- ⛽ **Стоимость топлива** (расчёт по 14 руб/км)
- 💰 **Стоимость командировочных** (дни × сумма в день)
- 💵 **Итоговую стоимость поездки**
- 🏢 **Стоимость одного рабочего места** (итоговая стоимость / кол-во рабочих мест)
- 📊 **Количество обслуженных организаций**
- 👥 **Количество обслуженных рабочих мест**
- 🏁 **Возврат в Барнаул** как обязательную часть маршрута

## 🔌 API

### GET /api/organizations
Получение списка организаций по умолчанию.

### POST /api/upload-excel
Загрузка и парсинг Excel файла с данными организаций.

**Запрос:**
```json
{
  "excelData": "base64_encoded_excel_file"
}
```

**Ответ:**
```json
{
  "success": true,
  "count": 10,
  "organizations": [
    {
      "id": 1,
      "name": "ООО 'Пример'",
      "address": "Барнаул, улица Ленина, 10",
      "workplaces": 15,
      "lat": 53.3606,
      "lng": 83.7617
    }
  ]
}
```

### POST /api/geocode
Геокодирование адреса (получение координат по адресу).

**Запрос:**
```json
{
  "address": "Барнаул, проспект Ленина, 50"
}
```

**Ответ:**
```json
{
  "success": true,
  "lat": 53.3515,
  "lng": 83.7505,
  "displayName": "Барнаул, городской округ Барнаул, Алтайский край, Россия"
}
```

## 📝 Примеры использования

### Пример 1: Расчёт на 3 дня
1. Откройте http://localhost:3000
2. Укажите количество дней: 3
3. Укажите командировочные: 1500 руб/день
4. Нажмите "Рассчитать маршрут"
5. Изучите результаты на карте и в статистике

### Пример 2: Свои организации
1. Подготовьте JSON со списком организаций
2. Вставьте в поле "Список организаций"
3. Настройте параметры поездки
4. Рассчитайте маршрут

## 💡 Рекомендации по использованию

- Для коротких поездок (1-2 дня) выбирайте организации в одном направлении
- Для длинных поездок (5+ дней) система автоматически разобьёт маршрут на кластеры
- Оптимальное количество дней для полного охвата Алтайского края: 5-7 дней
- Стоимость одного рабочего места помогает оценить экономическую эффективность поездки
